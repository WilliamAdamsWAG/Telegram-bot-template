# Security

We take the security of our project seriously. If you discover a vulnerability, please report it to us following the guidelines below.

## Reporting a Vulnerability

To report a discovered vulnerability, please email us at williamadams.aurora@gmail.com. Please include as much detail as possible, including:

- Version of the software used.
- Steps to reproduce the issue.
- Potential impact of exploiting the vulnerability.

We ask that you refrain from publicly disclosing the issue until it has been resolved.

## Handling Vulnerabilities

After receiving a vulnerability report, we will follow these steps:

1. Confirm the vulnerability.
2. Assess the severity of the threat.
3. Address the vulnerability and release fixes.
4. Notify users about the availability of patched versions.

The response time and resolution of the vulnerability depend on its complexity and impact on the system.

## Credits to Security Researchers

Security researchers who responsibly disclose significant vulnerabilities will be acknowledged on README and receive appropriate recognition.

Thank you for helping keep our project secure!
